# 🚢 Titanic Data Analysis using Python

## 📌 Project Overview
This project performs data cleaning, feature engineering, exploratory data analysis (EDA), and reporting on the Titanic dataset using Python and Pandas.

## 📂 Dataset
- Titanic Dataset (Kaggle)

## 🛠 Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook / Kaggle Notebook

## 📊 Tasks Performed

### Data Cleaning
- Handled missing values
- Filled Age using median
- Filled Embarked using mode
- Removed unnecessary columns

### Feature Engineering
- Family_Size
- Is_Alone
- Fare_Per_Person
- Fare_Category
- Premium_Passenger
- Age_Group
- Gender_Code

### Data Analysis
- Total passengers
- Survival rate
- Passenger class analysis
- Average age by class
- Average fare by class
- Gender-wise survival
- Solo vs Family travellers
- Top 10 highest fare passengers

## 📁 Output
- Titanic_Final.csv
